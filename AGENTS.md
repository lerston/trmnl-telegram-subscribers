# Telegram Subscribers

- Read README.md and CONTRIBUTING.md before changes.
- Keep this repository limited to the Telegram Subscribers plugin.
- Use a codex/<name> branch and pull request for code, Liquid, configuration and integration changes.
- Run the unit tests and ZIP/preview build before push.
- Test fixtures must be fictional. Never commit credentials, tokens, device dumps, local addresses, saved production state or private channel data.
- Report local, cloud TRMNL and physical-device verification separately.
- The project is in testing. Publishing a GitHub change does not authorize publishing a TRMNL Recipe or changing a device playlist.
